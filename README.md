# 💜 Projeto Ultravioleta

Site interativo, explicativo e moderno sobre a **Radiação Ultravioleta (UV)**, desenvolvido com foco em design futurista, animações em 3D, mini-jogo temático e uma IA assistente exclusiva.

---

## 🚀 Funcionalidades
* **Design Ultravioleta:** Paleta de cores imersiva em tons de roxo profundo, violeta neon e ciano.
* **Modelo 3D Interativo:** Sol UV e simulações visuais em Three.js.
* **Espectro UV:** Explicação detalhada sobre UVA, UVB, UVC e métodos de fotoproteção.
* **Vídeo Explicativo:** Seção multimédia interativa.
* **Mini-Jogo "Escudo Anti-UV":** Jogo dinâmico com modos fácil/difícil e itens de regeneração de escudo (`FPS 100+`, `Pós-Sol`).
* **Dersa (IA Especializada):** Assistente virtual inteligente programada exclusivamente para tirar dúvidas sobre radiação ultravioleta.

---

## 🛠️ Tecnologias Utilizadas
* **HTML5** / **CSS3**
* **JavaScript (Vanilla)**
* **Three.js** (para os elementos 3D)

---

## 📂 Como Executar o Projeto
1. Certifica-te de que tens todos os ficheiros na mesma pasta (`index.html`, `style.css`, `script.js`, `logo.svg`) e as fotos dos participantes).
2. Abre o ficheiro **`index.html`** num navegador web moderno (Google Chrome, Edge, Firefox, etc.) ou utiliza uma extensão como o *Live Server* no Visual Studio Code.
